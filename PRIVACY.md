# Privacy Policy

Folder Prettifier respects your privacy. Here's what you need to know:

## What we collect

**Nothing.** Folder Prettifier runs entirely on your machine. It does not collect, store, or transmit any personal data, files, or usage statistics.

## Network requests

The app downloads a file called `catalog.json` from a remote server on startup. This file contains the rules for sorting files (which extension goes into which folder). No data about you or your files is sent as part of this request.

## Third-party services

No third-party analytics, tracking, or telemetry services are used.

## Changes

If this policy changes, it will be updated here.
