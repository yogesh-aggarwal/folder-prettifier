WHAT IT DOES

Designed with care. Focused on essential utility.

01

Sorts Everything Automatically

Throws every file into the right category folder automatically. Videos go to Videos, PDFs to Documents, photos to Images. Custom rules ship pre-configured.

02

Cleans Up Names

Fixes awkward capitalization, swaps out underscores, strips trailing numbers like (1) or _copy, and applies proper Title Case.

03

Automatic Undo Backup

Makes a snapshot backup before touching any file. If you ever change your mind, put everything right back with a single click.

04

Lives on a USB Stick

Single portable executable file with zero dependencies. Keep it on a USB flash drive and run it from anywhere, anytime.

05

Right-Click Magic

Integrates into Windows File Explorer context menu. Right-click any messy folder and pick Folder Prettifier for instant cleanup.

06

Works 100% Offline

Your sorting rules stay local on your device. Optionally grabs the latest extension rules when online, but runs completely private offline.

GETTING STARTED

Three clicks and the job is done.

  1. 1

    Pick your dumpster fire

    Open the app or right-click any folder directly in Windows File Explorer (your Downloads folder is a great candidate).

  2. 2

    Tell it what to do

    Toggle Categorize files or Prettify names on or off. Tweak capitalization rules or rename the whole folder if you're feeling fancy.

  3. 3

    Hit Process and watch

    Stand back. Files instantly fly to their proper subfolders and file titles become clean and readable.
