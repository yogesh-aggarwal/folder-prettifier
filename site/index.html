Questions, answered

Is it safe to run?

It makes a backup before it touches anything. Nothing moves until you approve the plan.

What does it do to my files?

It moves files into category folders and rewrites names using your rules. Files stay on the same drive, only better organized.

Does it work offline?

Yes. Fresh sorting rules download when you are online, but everything runs locally with no account.

Do I need to install .NET?

No. It ships as a single file that runs on Windows 7 and newer, settings intact.

Is it really free?

Really. It is open source under the MIT license, and it stays free forever.
